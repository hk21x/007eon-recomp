A fix release of the unofficial native PC port of 007: Everything or Nothing (original Xbox).

## NVIDIA graphics cards: the MI6 Training freeze is fixed

**If you have an NVIDIA graphics card, update to this release.** On NVIDIA cards, version 1.0.0 froze in the second
mission (MI6 Training), in the hand-to-hand combat room, as the third enemy came in. The picture stopped and Windows
reset the graphics driver ("device lost", or a crash with DXGI_ERROR_DEVICE_HUNG in the log). It happened every time,
with Direct3D 12 and Direct3D 11 alike, so the game could not be played past that point. AMD and Intel graphics were
not affected.

The cause: the third enemy's model reads its vertex data through offsets far larger than Direct3D allows. Other
graphics cards read them anyway; NVIDIA's stop. The port now gives the card the same data in the form Direct3D
expects. The fix was tested on an NVIDIA card past the hand-to-hand room with both renderers.

Also for NVIDIA cards: busy scenes in the same mission could reuse some of the graphics card's resources while it was
still drawing with them, which could also freeze the game. The port now waits for the card first.

## Other changes

- The game's log (`EoN\play\logs`) now records the graphics driver's version, the memory in use every few seconds,
  and more detail when the graphics device is lost, so any further reports can be traced.

## Updating

Open **EoNLauncher.exe** (the one you already have, or this release's) and press **Build**: it downloads the latest
source and rebuilds the game from your disc with the fix. Your saves and settings in `EoN\play` stay as they are.

No game files are included. You need your own copy of the game (the European PAL release). See the
[v1.0.0 notes](https://github.com/hk21x/007eon-recomp/releases/tag/v1.0.0) for getting started.

Problems: the game's log is in `EoN\play\logs`, the launcher's in `EoN\launcher.log`.
